Entry for the [make.fun bounty "One-Sentence Absurd Invention Pitch"](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a).

## What the program does

`main.py` (pure Python standard library, no network, no model calls)
writes exactly one sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).

## The pitch

**The Apology Toaster** — a toaster that files a formal written
complaint every time you burn the bread, then refuses to pop up until
you apologise in writing.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/toaster-test python3 main.py
cat /tmp/toaster-test/entry.txt
```
